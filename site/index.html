Dogfood Bench

Is Claude Code fixing its own issues faster?

Anthropic builds Claude Code with Claude Code. If AI makes software engineers more productive, the effect should show up in the claude-code issue tracker. This page measures it.

Caveat: this page is 100% vibe coded with Claude Code. If the numbers are wrong, that is also a data point.

Method

A script reads every issue in the repository from the GitHub API. It records when each issue opened, when it closed, the close reason, and who closed it. Each closure goes into one bucket.

Fixed
Closed as completed by a person who did not open the issue.
Declined
Closed as not planned or duplicate by a person who did not open the issue.
Closed by author
The reporter closed it. The reason is unknown.
Bot sweep
A bot closed it, usually as stale, invalid, or duplicate.

Only fixed issues count as evidence of work. The page uses complete UTC weeks only. Vertical lines mark model releases. The data refreshes daily. Last fetch: unknown.

Limits: the "completed" reason is set by the person who closes the issue, and some issues close as completed with no fix. Issue volume also grows with the user count, so a falling fix rate can mean popularity, not decline. This is a half serious benchmark.
